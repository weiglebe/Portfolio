## Projects

### 1. Static Company Website on AWS

- **Tech:** AWS EC2 (Windows Server), IIS, S3, IAM, HTTPS
- **Date:** April, 2026
- **Summary:** I hosted a static website on a Windows Server EC2 instance running IIS, secured with HTTPS, with a contact form that stores consumer submissions in S3.
- **What I built:**
  - Configured IIS to serve the site
  - Set up HTTPS with a self-signed certificate
  - Connected a contact form to an S3 bucket, with IAM permissions and CORS configured so the browser could submit to it
